# Roll a Ball: Minecraft Edition

Game created as the first project for the "Game Programming" course - Roll a Ball. Developed using the Unity Engine, version 6000.0.82f1.

> **Advisor:** Murilo Boratto <br>
> Game produced using Unity, published on Unity Play. <br>

The objective of the game is to collect 10 coins in 35 seconds. <br>
Controls: 
WASD or ← ↑ → ↓ <br>

Play the project by clicking [here](https://play.unity.com/en/games/6e6dd6ef-9fd8-4ebb-8208-8c32ca868e94/rola-bola-3d)
